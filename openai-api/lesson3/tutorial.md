**Streaming Responses**: The OpenAI API supports streaming responses, which allows you to receive partial results as 
they are generated. This can be useful for applications that require real-time feedback or for displaying results 
incrementally.

This is what we did so far:


You: Explain recursion
        ↓
       OpenAI
        ↓
   [wait for complete response]

        ↓
AI: Recursion is a programming technique...

With Streaming Responses, you can receive the response in chunks as they are generated:

You: Explain recursion
        ↓
       OpenAI
        ↓
AI: Recursion
AI: is
AI: a
AI: programming
AI: technique
AI: where...

If the model generate a 500 word answer, the user sees nothing for 3 seconds. With streaming, the user sees the answer immediately, word by word, **which is a better user experience.**

```
earlier:
response = client.responses.create(
    model="gpt-5",
    input=conversation
)

now:
stream = client.responses.create(
    model="gpt-5",
    input=conversation,
    stream=True
)
```

```
from openai import OpenAI
client = OpenAI()
response = client.responses.create(
    model="gpt-5",
    input="Explain recursion in simple terms.",
    stream=True
)

for event in response:
    print(event)
```


1. The stream contains different types of events and we only care about the `response.output_text.delta` events, which contain the text generated by the model. 
The other events are useful for debugging and understanding the model's behavior, but they are not necessary for most applications.
2. `print(event.delta, end="", flush=True)`. flush=True tells python to display the output immediately.
3. stream is something you can iterate over. 
   ```
   for event in stream:
    ...
    ```
4. event.delta is the text generated by the model. You can use it to display the response in real-time. It represents the incremental output of the model as it generates text. 
   You can append it to a string or display it directly to the user.

   Suppose the model ultimately generates: Python is easy to learn.

   You might receive pieces resembling:
   "Python"
   " is"
   " easy"
   " to"
   " learn"
   "."
